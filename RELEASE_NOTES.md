# SubGrab 1.0.0

SubGrab finds, fixes and saves subtitles (SRT) for the movies and TV series in a folder, or by name or IMDb id.

## Downloads

| File | Use it when |
|------|-------------|
| `SubGrab-Setup.exe` | Windows installer. |
| `SubGrab-portable.zip` | Windows, no install. |
| `SubGrab-macOS.dmg` / `SubGrab-macOS.zip` | macOS. |
| `SubGrab-x86_64.AppImage` / `SubGrab-linux.tar.gz` | Linux. |
| `SHA256SUMS*.txt` | Check your download. |

## What you get

- Sources: OpenSubtitles.com and SubSource (you add your own free key in Settings), plus Subf2m and other optional fallbacks.
- Exact file-hash matching and release-name scoring. Weak matches wait for your review.
- Converts to UTF-8 SRT, removes ads and hearing-impaired notes, shifts timing, renames videos to clean names with Undo.
- Dark and light themes.

## First start

The builds are not signed with a paid certificate, so your system may warn you. On Windows choose More info, then Run anyway. On macOS open System Settings, Privacy and Security, then Open Anyway. Compare the SHA256 file with your download if you want to check it.

## Checked before release

The installer is installed silently, the installed app is started and its window must load, then it is uninstalled. The same start check runs for the Windows, macOS and Linux builds. Live subtitle searches depend on the source websites and on your own key.
